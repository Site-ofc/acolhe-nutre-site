# Acolhe & Nutre

Site institucional estático e responsivo da Acolhe & Nutre, com navegação para celulares e computadores, apresentação dos serviços, equipe, localização e contato por WhatsApp.

## Executar localmente

Requer Node.js 18 ou superior e Python 3. Para compilar o site estático:

```bash
npm run build
```

Para visualizar o resultado no navegador:

```bash
npm run serve
```

A prévia local abre em `http://localhost:8000`. Não há dependências JavaScript de terceiros para instalar. As fontes tipográficas usam Google Fonts, com alternativas de sistema caso não carreguem.
